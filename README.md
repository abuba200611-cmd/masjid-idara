# إدارة الجامع

طبقة تنظيمية فوق [حلقات (halaqat-tahfeez)](https://halaqat-tahfeez.vercel.app) — لا تكرّر بيانات
الحفظ أو التسميع، فقط تربط كل حلقة بجامعها وتوزّع الطلاب الجدد.

- **جامع** يضمّ عدة **حلقات** (كل حلقة تعيش فعلياً في نظام المعلّم، ونربطها هنا برمز دعوتها).
- **رابط تسجيل عام لكل جامع** — الطالب الجديد يسجّل اسمه ورقمه بدون اختيار حلقة.
- **مشرف الجامع** يوزّع كل طالب جديد على حلقة مناسبة، فيُضاف تلقائياً لقائمة ذاك المعلّم
  بنظام حلقات — بلا أي إدخال يدوي إضافي.

## التشغيل محلياً

```bash
npm install
npm run dev
```

يحتاج `.env.local` بمتغيرات: `NETLIFY_DB_URL` (قاعدة Postgres خاصة بهذا المشروع)،
`ADMIN_SECRET` (كلمة سر لوحة الإدارة)، `LINK_SECRET` و`TEACHER_APP_URL` (نفس السرّ وعنوان
نظام حلقات، للنداءات الخادمية بينهما).

## البنية

- `lib/db.ts` — طبقة الوصول لقاعدة بيانات هذا النظام (جوامع/حلقات/طلاب بانتظار التوزيع).
- `lib/teacher-app.ts` — عميل النداءات لنظام حلقات (التحقق من رمز الدعوة، إضافة الطالب فعلياً).
- `lib/admin-auth.ts` — جلسة مشرف واحدة (كوكي يحمل السرّ، بلا جدول مستخدمين).
