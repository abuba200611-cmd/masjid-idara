# بيانات الجوامع — مجلد الاستيراد

هنا تُوضع بيانات كل جامع كما يرسلها صاحب النظام: مجلد فرعي لكل جامع،
وكل ملف `.md` داخله يصير ملاحظة في **دماغ** ذلك الجامع.

```
mosques-data/
  <اسم-الجامع>/
    mosque.json          ← اختياري: { "name": "جامع النور", "city": "الرياض" }
    خطة الحلقات.md
    المراجعة الأسبوعية.md
    ...
```

## صيغة ملف الملاحظة

- **العنوان**: أول سطر يبدأ بـ `# `، وإن لم يوجد فاسم الملف بلا امتداده.
- **الوسوم**: إن كان أول سطر غير فارغ بالشكل `tags: وليمة, أطفال` تُقرأ
  وسوماً (تقبل الفاصلة العربية `،` أيضاً) ويُحذف السطر من المحتوى.
- **المحتوى**: باقي الملف كما هو — ماركداون بسيط (عناوين، قوائم، **عريض**،
  روابط)، والوصلات الداخلية بصيغة `[[عنوان ملاحظة أخرى]]` تعمل كما في
  الدماغ: موجودة فوصلة عادية، وإلا ظهرت حمراء وتُنشأ بالضغط عليها.

## الاستيراد

السكربت يعمل **upsert بالسَلَغ**: يشغّل مرات عدة بأمان — يضيف الجديد
ويحدّث المتغيّر ويترك المطابق. تحتاج رقم الجامع (id) بعد إنشائه من لوحة
المشرف العام، ومتغيرات الاتصال من `.env.local`:

```bash
# معاينة فقط — يطبع ما سيتغيّر ولا يكتب شيئاً
node -r dotenv/config scripts/import-brain.mjs mosques-data/<اسم-الجامع> <mosqueId> dotenv_config_path=.env.local --dry-run

# التنفيذ الفعلي
node -r dotenv/config scripts/import-brain.mjs mosques-data/<اسم-الجامع> <mosqueId> dotenv_config_path=.env.local
```

`mosque.json` لا يستورده السكربت — هو مرجع اسم الجامع ومدينته عند إنشاء
حسابه يدوياً من اللوحة.

> ملاحظة: بيانات الجوامع هنا قد تحوي أرقام تواصل وأسماء أسر — لا تُرفع
> لمستودع عام.
